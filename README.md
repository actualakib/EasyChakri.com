# EasyChakri.com

Welcome to EasyChakri.com! This project is designed to provide an efficient platform for job seekers and employers to connect in a user-friendly environment.

## Project Documentation

### Features
- Job listings
- Resume uploads
- Employer profiles
- Job seeker profiles
- Application tracking
- Notification system

### Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB

## Setup Instructions

### Prerequisites
- Node.js installed
- MongoDB installed

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/actualakib/EasyChakri.com.git
   ```
2. Navigate to the project directory:
   ```bash
   cd EasyChakri.com
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

Visit `http://localhost:3000` in your web browser to access the application.
